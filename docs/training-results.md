## 已完成实验如何影响新策略

V1 Controller 训练 1,000,448 tokens 后停止：真实混合路径 Fixed/Extra CE=7.002387/7.118595，未达到 Gate；主模型冻结。V2 使用独立 calibration 选择三类启发式阈值后，真实混合路径仍未通过，V2 新增训练 token 为 0。详见 [V2 scoreboard](evidence/2026-09-17/dynamic-v2-scoreboard.csv)。

R4 的 Fixed CE=9.500763，高于 R3=6.872182；R4–R8 是当前训练深度之外的外推区域。Cached Oracle 的低 CE 使用真实目标事后选择，不能据此推断真实路由一定有效或已获得速度收益。这些观测支持暂停当前异步实现，没有对混合状态问题作完整因果识别。
