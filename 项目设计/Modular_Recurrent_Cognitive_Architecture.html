CONCEPT ARCHITECTURE

模块化循环认知架构

以统一“意识空间 / 工作空间”为核心，让语言、视觉、音频、控制等能力成为可组合的 R 循环模块；执行器读取当前循环产生的意图，动态决定下一轮激活哪些 R，从而形成持续、可调度、可校正的闭环思考。

统一认知空间模块化多模态动态 R 路由局部更新全局注意力校正算力可控
01 · PURPOSE

创建这个架构的目的

不是制造一个必须同时运行全部能力的巨大单体模型，而是建立一个持续存在的认知核心：需要什么能力，就让对应模块进入当前循环，共同更新同一份认知状态。

摆脱固定流水线

思考不再只是一次前向传播，而是“状态 → 选择 → 局部计算 → 更新 → 再选择”。

多模态真正统一

统一的是共享认知状态，不要求图像、音频、文本都使用相同网络。

按需分配算力

当前只关注听觉，就只激活语言、音频和必要记忆；生成视频时再调入视觉、时序和音频模块。

能力持续扩展

未来增加触觉、机械控制等能力时，重点训练新 R 与核心的联合认知对齐。

02 · MINIMAL CLOSED LOOP

最简单闭环：主 R → 解码器 → 执行器 → 下一轮 R

输入 / 当前状态
主 R 循环
更新 Workspace
当前执行模块的解码器
把状态变成操作意图
执行器 / Router
决定下一轮激活谁
↺ 执行器选择下一轮 R 组合，并把新输入 / 反馈送回 Workspace

执行器网络承担的是认知调度：解析当前 R 的下一步意图，决定下一轮调用哪些 R 循环体、运行次数、资源预算和输出头。

03 · DYNAMIC COMPOSITION

R 模块按任务动态组合

R Language
R Vision
R Audio
R Control
R Memory

专注听内容

Language + Audio (+ Memory)

图像问答

Vision + Language

视频生成

Text + Vision + Temporal + Audio

摄像机控制

Vision + Control + Language

组合不是固定的。摄像机控制可以三个模块同时激活，也可以按训练目标采用 Vision-Control、Language-Control、Vision-Language 等两两耦合。

04 · SHARED WORKSPACE

统一的是认知空间，而不是所有模块的结构

Text Encoder ─────┐
Vision Encoder ───┼─────┐
Audio Encoder ────┤     ▼
Control Feedback ─┘  ┌────────────────────┐
                     │ Shared Workspace   │
                     │ Persistent State S │
                     └────────────────────┘
                         ▲          │
                         │          ▼
                  Specialized R Modules
                         │
                  Router / Executor
                         │
                         └────────────↺

新模块可以拥有独立结构，但训练时要与核心语言 / 认知模块共同参与，使它学会在同一个 Workspace 中表达、读取和修改状态。

05 · ATTENTION TEACHER

训练方向一：完整注意力作为循环体教师

教师路径

S*t = FullAttention(history + new input)

得到加入新信息后，历史与新输入充分融合的高质量状态。

循环路径

Ŝt = R(St-1, Δinput)

R 学习在不重算全部历史的情况下更新状态。

训练同时包含状态对齐和任务解码，让 R 学的是“认知状态如何变化”，而不只是 next-token。

06 · COUPLED TRAINING

训练方向二：特定耦合联动训练

例：摄像机控制

Vision + Language + Control：视觉判断画面，语言 / 核心表示目标与计划，控制模块输出移动、旋转、缩放、对焦等操作。

Vision + Control：视觉闭环跟踪；
Language + Control：指令到控制策略；
Vision + Language：场景理解与空间关系。

模块可以局部专业化，但认知语义通过与核心联合训练保持一致。

07 · DRIFT & CALIBRATION

训练方向三：漂移累计模型 + 全局注意力纠正

连续局部 R 循环可能产生误差累计，因此显式训练漂移估计器，预测当前状态距离完整全局计算状态有多远。

Estimated Drift

if drift > τ → Full Global Attention / Calibration

当漂移达到阈值、模块冲突增大、任务切换或进入关键决策时，触发完整全局注意力重新整合信息并把 Workspace 重新锚定。

08 · LAYER-WISE GENERATION

生成也可以逐层关注，而非一次全部完成

第 1 轮

布局 / 镜头 / 角色位置

第 2 轮

人物主体与姿态

第 3 轮

背景与空间关系

第 4 轮

图层、材质、局部细节

第 5 轮

动作 / 时序连续性

第 6 轮

音频 / 配音 / 口型同步

Router 可以把下一轮计算集中到某个图层、对象或模态，而不是要求所有内容同时被修改。

09 · SCALING PATH

从最简单到多种搭配

Stage 1

单一语言 R
验证循环状态、Attention Teacher、漂移与全局校正。

Stage 2

Language + Vision
验证共享 Workspace 和双模块联合训练。

Stage 3

+ Audio
验证双模块 / 三模块动态组合和 Router 学习。

Stage 4

+ Control
形成感知 → 思考 → 执行 → 新感知的闭环。

Stage 5

更多专业 R
触觉、机械控制、空间、记忆、工具等按需接入。

10 · CORE LOOP

最终核心闭环

S_t → Router / Executor → {R_i, R_j, ...} → ΔS_t → S_(t+1) → Decoder / Action → Feedback → ↺

统一状态、模块计算、动态路由、局部更新、漂移监测、全局校正。
